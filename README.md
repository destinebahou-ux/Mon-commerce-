# MON COMMERCE — prototype gratuit

Application de démonstration pour gérer produits, stock, ventes, dépenses et dettes.

## Important
- Cette version conserve les données dans le navigateur de l'appareil.
- Elle ne synchronise pas les données entre plusieurs téléphones.
- Exportez régulièrement une sauvegarde avec le bouton prévu.
- Pour l'installation comme application, hébergez les fichiers sur un site HTTPS (par exemple GitHub Pages), puis ouvrez le site dans Chrome et choisissez « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Prototype de départ : avant une utilisation commerciale réelle, il faudra tester, améliorer la sécurité, les sauvegardes et la synchronisation.
